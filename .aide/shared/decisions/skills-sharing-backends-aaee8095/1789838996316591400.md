# skills-sharing-backends

**Decision:** Skill sharing uses portable backend-independent bundles and a publishing-backend abstraction. Local-file is the first implementation; remote HTTP/registry backends such as ClawHub follow.

## Rationale

User explicitly chose local sharing first while requiring a portable publishing concept extensible to remote backends.
