# container-main-deployment

**Decision:** Every main-branch build publishes matching main and latest GHCR tags plus an immutable SHA tag. Only main moves those aliases. The homelab Lobslaw StatefulSet in namespace hermes follows main through Keel with force, match-tag=true, one-minute polling and Always pulls for both the agent and certificate init container. This supersedes manual SHA-only deployment for Lobslaw; other workloads are unaffected.

## Rationale

The user explicitly requested main/latest publishing and automatic cluster redeployment, then specifically approved Keel rollouts for Lobslaw. Reuse the installed controller without adding GitHub cluster credentials. Retain SHA tags and retention pins for recovery.
