# lobslaw-portable-backups

**Decision:** Provide a dedicated versioned logical import/export and backup mechanism for memories, skills, cron schedules, reminders and commitments, with embeddings rebuilt using the destination model on import.

## Rationale

User requested moving the actual local Lobslaw stack state between deployments and retaining versioned backups. Embeddings are derived, while original text, summaries, ownership, provenance, skill versions and scheduled work are durable content.

## Details

Design requirements agreed in this session. Implementation proposal is docs/dev/BACKUP.md; archive encoding, conflict policies and activation defaults there remain proposed. Do not mistake this decision for authorization to overwrite an existing deployment or execute an import.
