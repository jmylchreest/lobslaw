# user-scoping-ownership-model

**Decision:** Records carry an explicit owner and a visibility enum; cross-owner access is an authorization decision made by the policy engine, not a query-layer special case. One mechanism serves both single-user-with-guests and multi-user deployments — the difference is data, not a mode flag.
