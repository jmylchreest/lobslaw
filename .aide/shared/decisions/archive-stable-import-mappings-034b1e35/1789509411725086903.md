# archive-stable-import-mappings

**Decision:** Import-alongside uses a durable mapping from source identity, record kind and source record ID to destination record ID across backup generations. Repeated unchanged imports skip the mapped record. Source changes conflict against the mapped destination copy. Destination edits or deletions are surfaced explicitly and never silently overwritten, recreated or duplicated. Session indexes and transcript references are resolved together. Snapshot IDs and content-based retry receipts are not source identity.

## Rationale

Approved by the user after identifying that fresh IDs on each import would create duplicates. Persistent provenance distinguishes changes to one source record from a new record and preserves destination edits and deletions. Existing content-based import receipts remain useful for crash recovery but cannot provide cross-generation identity.
