# archive-explicit-replacement

**Decision:** Conflicts are resolved per record group with explicit replace, alongside or skip choices. Replacement requires a verified, pinned encrypted destination backup and commits all selected replacements and additions in one bounded Raft transaction guarded by the portable destination state digest. Session replacement includes its complete transcript. Stable source mappings make unchanged retries no-ops; each new replacement transaction uses a fresh receipt ID so recovery to an earlier state cannot hide an explicit replacement.
