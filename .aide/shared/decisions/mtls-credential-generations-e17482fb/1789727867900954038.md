# mtls-credential-generations

**Decision:** Publish certificate, cluster roots, client-auth roots, operator anchor and node identity as one immutable atomic generation. Serialize Reload and TrustOperatorCA. Retained gRPC client credentials and clones capture the current generation per handshake and delegate verification to standard gRPC TLS; operator roots remain excluded from outgoing verification. NodeID is a synchronized accessor.

## Rationale

Issue 297: startup-captured roots break CA rotation on retained Raft credentials; separate mutable fields also allow races and incoherent handshakes.
