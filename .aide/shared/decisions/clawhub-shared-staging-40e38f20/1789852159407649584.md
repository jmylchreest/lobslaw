# clawhub-shared-staging

**Decision:** All live ClawHub entry points use shared skill validation and Raft staging. The plugin CLI is a compatibility wrapper; the agent tool can only propose for its authenticated canonical owner under an explicit skills:share:propose grant. Human activation is separate; retrieval and proposals never bootstrap dependencies or create execution policy grants.
