# pretooluse-argument-rewrites

**Decision:** PreToolUse modify responses use hookSpecificOutput.updatedInput as a string-valued argument patch. Apply patches in hook order and pass effective input to subsequent hooks. Preserve original hard denials, then validate and gate the final input before dispatch. Persist prepared input and answered gates in the server-owned confirmation continuation, bound to the turn and exact tool call; resume skips pre-hooks but reevaluates current policy and safety. Prepared answers never override a denial or carry into another call. Reject unsupported modifications and correct the public schema documentation.

## Rationale

Issue 294 silently discarded rewrites. Applying them after approval would authorize different arguments, and rerunning hooks on resume could change the approved operation or repeat side effects.
