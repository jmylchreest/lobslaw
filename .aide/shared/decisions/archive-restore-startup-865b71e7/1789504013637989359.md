# archive-restore-startup

**Decision:** Use explicit memory.restore_mode for logical restores: suppress gateways, scheduling and user preference seeds while retaining authenticated archive RPCs and destination embedding. Import execution state stays paused after leaving restore mode.

## Rationale

Normal startup seeds knowledge records and schedules before restore, defeating an empty-target restore and risking execution during recovery. Runtime config remains the authority for when normal operation resumes.
