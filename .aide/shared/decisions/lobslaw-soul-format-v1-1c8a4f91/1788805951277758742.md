# lobslaw-soul-format-v1

**Decision:** SOUL.md retains YAML frontmatter plus Markdown. Optional schema_version: 1 enables strict known-field decoding, neutral default score 5 for omitted numeric style dials, explicit zero as a low score, and preserved zero adjustment settings. Legacy unversioned parsing and zero-as-unset rendering remain supported. New operator file fields are verbosity (concise/balanced/detailed) and language.spelling_locale (language tag); introspection exposes them but chat tuning retains its existing fields. language.detect selects a turn-local reply default from only the current user question. Explicit user requests override style defaults. Passive personality adaptation remains disabled.

## Rationale

User requested further format investigation and implementation while preserving the separation between style configuration and the user question. Versioning makes stricter semantics opt-in. This extends lobslaw-soul-effective-state, superseding only its no-new-schema-keys implementation note; storage, policy, reload and prompt-boundary decisions remain unchanged.
